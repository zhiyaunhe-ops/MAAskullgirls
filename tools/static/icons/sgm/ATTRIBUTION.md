# Skullgirls icon assets

Original character mastery and elemental artwork, sourced without modification
from [Krazete/sgm](https://github.com/Krazete/sgm/tree/aa3099a43f4ed0dff052040c02bbcbdf0338ec05/image/official),
revision `aa3099a43f4ed0dff052040c02bbcbdf0338ec05`. These are game artwork, not artwork created by MAAskullgirls.
Skullgirls and its original artwork belong to their respective rights holders.

Bundled locally so the WebUI does not need the optional `sgm/` checkout
or remote image requests.
